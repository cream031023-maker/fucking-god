# 筑库 · BIM 族库协作平台（MVP）

一个可运行的族库协作演示，包含**操作端**和**客户端**，演示族库条目管理、发布审核、搜索筛选与服务端数据同步。界面与交互参考通用 BIM 族库产品形态，不复制品茗科技的商标、代码或专有素材。

## 启动

需要 Node.js 18 或更高版本，无需安装依赖：

```bash
npm start
```

浏览器访问 <http://localhost:3000>。需要让多台设备联调时，将服务部署到可访问的服务器，并使用该服务器地址访问；客户端每 4 秒轮询服务端数据版本，更新会自动显示。服务端数据保存在 `data/library.json`。

## 已实现

- **客户端**：浏览已发布族库条目、关键词搜索、分类/专业筛选、记录获取、浏览器本地收藏、手动同步。
- **操作端**：总览、创建条目、编辑发布状态、撤回到草稿、审核草稿、删除条目、查看获取统计。
- **同步**：所有条目写入同一服务端 JSON 数据文件；客户端和操作端轮询同一 API。发布/删除等变更在数秒内同步到其他在线浏览器。
- **安全提示**：这是仅用于原型验证的 MVP。未实现账号/权限校验，操作端开关只是演示 UI，不能用于公网生产。正式部署前应加入身份认证、RBAC、数据库与审计日志、上传文件存储/病毒扫描、HTTPS、并发写入保护和备份。

## 主要接口

- `GET /api/library`：获取已发布条目；`?includeDrafts=true` 用于展示所有条目。
- `POST /api/items`：创建条目。
- `PATCH /api/items/:id`：更新条目状态或字段。
- `DELETE /api/items/:id`：删除条目。
- `POST /api/items/:id/download`：记录获取次数。

当前“获取族文件”仅记录统计，不传输真实 RFA/RVT 文件。真实文件上传、预览及桌面软件插件集成需要后续接入对象存储和对应客户端能力。
